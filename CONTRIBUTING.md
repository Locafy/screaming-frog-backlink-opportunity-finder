# Contributing

Thanks for helping improve the Screaming Frog Backlink Opportunity Finder.

## Before opening a pull request

1. Create a focused branch from `main`.
2. Keep the snippet dependency-free and compatible with Screaming Frog Custom JavaScript extraction snippets.
3. Never add API keys, crawl exports, customer data, or proprietary prospect lists.
4. Add or update tests for behavior changes.
5. Run `npm test` and confirm it passes.

Please keep changes narrow, explain the user problem they solve, and include manual Screaming Frog verification notes when execution behavior changes.

## Reporting bugs

Open a GitHub issue with the Screaming Frog version, rendering mode, affected URL type, expected behavior, observed behavior, and a sanitized error message. Do not include API keys or private page content.

For security issues, follow [`SECURITY.md`](./SECURITY.md) instead of opening a public issue.
