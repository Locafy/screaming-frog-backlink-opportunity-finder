# Security Policy

## Reporting a vulnerability

Please use this repository's private **Report a vulnerability** option under the Security tab. Do not disclose exploitable details in a public issue.

Include the affected code path, impact, reproduction steps, and any suggested mitigation. Remove API keys, tokens, private page content, and customer information from the report.

## API-key safety

This project intentionally keeps credentials out of version control. Add your OpenAI API key only to a local working copy or your local Screaming Frog snippet configuration. If a key is committed, exported, logged, or otherwise exposed, revoke it in OpenAI immediately and create a replacement.

Only analyze content you are permitted to send to OpenAI. The operator is responsible for reviewing applicable privacy, contractual, and data-handling requirements.
